# VELOop Rewards — Design Preview

A static visual concept for the VELOop Rewards wallet, staking, mining, and payout experience.

## Preview

Open `index.html` in a browser, or serve this folder locally:

```bash
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Screens included

- **Login:** member sign-in concept.
- **Wallet:** illustrative VELOop balances, streak calendar, milestone, statistics, recent activity, and redeem prompt.
- **Stake & Earn:** staking overview and reward progress. Balances are illustrative; actual staking rules and terms must come from the platform.
- **Mine & Earn:** mining-inspired session dashboard with energy and upgrade concepts. This is a simulated in-platform rewards feature, not real cryptocurrency mining.
- **Payout:** UPI method, illustrative reward choices, and redemption summary.

## Design notes

- This repository contains a **static design preview** made with HTML and external CSS.
- Displayed balances, progress, activity, and payout values are illustrative examples.
- Login, forms, wallet balances, staking actions, mining session controls, and payout actions are not connected to an API or database.
- No production credentials or real payout integrations are included.
- VELOop's published [Mine & Earn guidance](https://www.velooprewards.in/help-center/earning/mining-rewards) describes this as a simulated feature, not real crypto mining.

## Files

- `index.html` — page structure and static sample content.
- `styles.css` — layout, responsive rules, typography, and visual styling.
